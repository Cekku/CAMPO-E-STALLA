## Installare l'app sul telefono Android

1. Dal telefono tocca **Scarica l'app Android** qui sopra: si scarica sempre l'ultima versione.
2. Apri il file `Campo-e-Stalla.apk` dalla notifica del download.
3. La prima volta Android chiede di permettere l'installazione da questa fonte: consentila, torna indietro e tocca **Installa**.

Per aggiornare si fa lo stesso: i dati salvati nell'app restano. Sui telefoni con Android 8 aggiorna prima *Android System WebView* dal Play Store.

La guida completa è in [LEGGIMI.md](LEGGIMI.md).
